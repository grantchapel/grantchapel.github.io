Auto-tag rules in this demo: Rush = next-day shipping · International = non-US address · Fragile = any glass/ceramic SKU · VIP = customer with 10+ orders · Gift = gift note present. Tags are added the moment an order arrives, so it lands in the right queue without anyone sorting it.
